# Validate traceable open engineering artifacts

Read the exact task revision and select the checks that address its acceptance criteria. This skill does not expand a task to the entire roadmap or authorize future implementation. These are validation instructions, not claims of an existing product.

1. Use the bounded environmental sensor reference. Record units, tolerances, coordinate systems, requirement IDs and tool versions across enclosure, board and bill of materials.

2. Change a supported parameter and regenerate editable geometry or electronics sources. Preserve cross-artifact identifiers; diagnose unsupported operations rather than substituting an opaque render.

3. Exercise a mismatched unit, oversized board, displaced mounting hole and missing component where relevant. The check must reject the counterexample and explain which requirement is violated.

4. Separate solver estimates, datasheet claims and physical measurements. Simulations include assumptions and a reference case; measurements name the actual built revision and equipment.

5. Reopen an exported package without private files. Physical fabrication, purchases and safety-critical use require their own agreed scope; a planning task or simulation result does not authorize them.

For every selected check, record fixture/setup, actions, expected outcome, observed outcome and reproducible evidence. State which checks were not applicable and why; do not count unrun checks as passing.
